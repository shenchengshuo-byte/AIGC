## 范围

开发规范属于专业工作建议；案例事实与情绪解释分别标注。现有观察仅涵盖三部同平台榜单剧的24集免费部分，采用抽样画面和烧录字幕核对；未连续听看音画、未听辨音轨、未验证付费结局及欧美地域商业效果。两份用户剧本19集仅作文本参考。情绪标签为预期/开发判断，不是观众实测。

本仓库未上传参考原件、完整视频、完整OCR字幕、凭据或临时签名媒体链接。当前版本不是百强全集研究完成报告，也不保证任何规范直接产生爆款。
