# 在自己的已登录TikTok浏览器中采集链接

适用桌面版Chrome或Edge。它操作正常搜索页面，不接管账号，不读取密码、Cookie或令牌。只收集页面上可见的视频/剧集链接及附近文字，不下载视频、不访问隐藏媒体、不向外部服务器传送结果。所有代码均可阅读。

1. 将这个文件夹解压到固定位置，确保manifest.json直接位于文件夹内。
2. Chrome打开 chrome://extensions （Edge用 edge://extensions），打开“开发者模式”，点击“加载已解压的扩展程序”，选择这个文件夹。
3. 保持TikTok已登录，点击扩展图标里的“TOP100链接采集”，点击“开始/继续”。它会新建一个专用搜索标签页，按89个不同剧名依次查找；运行时不要在这个专用页手动跳转。
4. 可随时暂停，进度保存在本机。点击“导出链接JSON”，将文件发回聊天，即可合并到100条榜单并核对剧名、账号与版本。

每项读取后至少等待30秒，加上加载和滚动，全部89项约需1小时以上，实际取决于页面。关闭弹窗不影响队列；关闭专用标签页会暂停。遇验证或连续两页无结果也暂停，不会自动处理验证或反复请求。正常页面恢复后可继续；导出记录会保留失败项。

采集结果只是搜索候选，不能直接当成榜单对应作品。即使页面文字含完整剧名，也需要核验发布账号、视频内容及是否同一版本。重复剧名在队列中只搜一次，100条原始名次与账号保留，不自动合并成一个IP。

第36名已按原榜图片改用Married to the Chief检索；原文件误录Married to the Thief的记录和更正说明保留在rank_data.json。

权限只用于本机保存进度、定时继续、读取www.tiktok.com搜索页；未申请cookies、webRequest或所有站点权限。未内置远程脚本，也没有服务器上传地址。使用结束后可移除扩展并删除本地数据。

当前执行环境无法复现你自己的登录状态。扩展已通过语法与离线队列/导出/链接校验。本环境管理员禁用加载未打包扩展，因此未完成浏览器安装或真实登录采集测试；你本机若允许安装，可按上述步骤使用，真实结果取决于TikTok访问状态。遇到无法采集的页面，导出已得结果即可，不要提供账号密码或登录令牌。
