### 4. 关系线的可迁移写法

【议】保留敌对合作与危险吸引，但将重要转折放在筹码交换上。可供修改会议讨论的一条路线是：互相利用→各自破坏合作并付代价→看见对方保护第三者→主动归还一部分选择权→有机会离开仍选择合作。此路线是建议，不是原稿后续事实。

若项目定位为黑暗爱情，可以保留人物的道德缺陷，同时让文本知道这些行为造成了什么后果。若定位为大众浪漫冒险，则应更早补上尊重边界与双方自主选择的行为。这是定位选择，不应混用一套宣传承诺而交付另一种关系。
