# 题材开发分册

V3.0｜开发策略，非市场收益排序。与《规范框架总纲》共同使用。

## A 关系重估与自主选择

核心问题：当认知、利益和权力改变时，关系是否值得继续，主角是否有真实选择。

立项必须设置：双方想从关系中取得什么、为什么不能轻易退出、误判依据、各自不愿付的代价。契约婚姻、旧爱重逢、婚后重建可作入口，不足以单独产生中段。

段落推进：先建立旧办法的代价，再以具体事件检验承诺，随后改变筹码与边界，最后通过可拒绝条件下的选择完成关系结算。复合、分离或错失均可成立，但应与主承诺一致。

主编要求：吸引、信任、原谅与恢复关系分别记录；重大伤害有事实和责任处理；女主/男主不能只因对方身份更高就改变价值判断。第三者可以是对手，但不把核心双方的责任全部转嫁给第三者。

常见失效：连续误会却不给无法解释的真实原因；每次保护后关系立刻归零；先承诺自主，后段只换一个控制者。需要返修人物欲望与权力图，不能只加吻戏。

本地化与制作：合同、婚姻、离婚和公司权限按地区核查；私密空间要写清退出和拒绝的条件。亲密感可以依赖小动作与选择，不一定依赖昂贵场景。

## B 能力竞争与地位改变

核心问题：被低估者能否在真实评价与资源阻碍下，用自己的能力改变处境。

立项必须设置：可以展示的能力、可判断成败的任务、评价者及利益、能力限制、资源差距。隐藏身份可以制造信息差，但不能替代能力本身。

段落推进：小任务证明方法；较大任务检验稳定性；对手改变评价条件迫使主角修正；最终任务结合专业选择与价值代价。胜利带来下一段权限，而不是每次都重新变回无人相信。

主编要求：关键胜负展示过程中的决定性选择；专业规则不随结果变化；贵人可提供入口，不能包办核心解法。成果、署名、报酬与话语权分开处理，不将旁人夸赞当全部回报。

常见失效：一句“她是天才”代替工作；所有对手靠愚蠢输；一亮身份就不必完成任务。返修任务和评价制度，补主角解题链。

本地化与制作：职业权限、证书、评审和支付条件需要可靠依据；如果无法呈现复杂专业过程，可把任务缩小成观众能观察到检验的步骤，不能假装已核验当地制度。

## C 家庭身份与资源重分配

核心问题：谁有资格被承认、谁占有资源、血缘与共同生活分别要求什么责任。

立项必须设置：亲情欲望与资源利益分别写清；身份真相的可验证证据；谁为何阻止查证；认出之前与之后分别会有什么冲突。身份揭晓不应把全剧冲突一次耗尽。

段落推进：身份线索改变小选择；证据引发同盟和利益分化；公开改判重分配资源；结局处理长期伤害、亲情边界与主角去留。

主编要求：真相、法律/制度权限、感情承认不可互相替代。亲生身份不是道德优越的证明，被养育关系也不应因一个反转自动归零；具体人物根据行为承担后果。

常见失效：检验报告随意生成且无人核查；认亲后自动痊愈；家庭成员只为拖延真相反复失去判断力。返修证据路径和揭晓后段落，而非再加一个真假继承人。

本地化与制作：继承、监护、婚生身份等随地区差异很大；虚构家规不能冒充当地法律。家族宴会可作公开验证场，但每场必须改变权限与关系，不只更换辱骂者。

## D 奇幻规则下的关系与生存

核心问题：特殊规则把人绑定或限制后，角色如何承担代价，取得力量、自由或互相选择。

立项必须设置：能力/契约的触发、作用、范围、限制、代价和解除条件；谁知道规则；未知部分如何学习。狼人、海妖、龙族是世界选项，不是现成的情绪发动机。

段落推进：先在小后果中证明规则，再由角色错误使用/被利用付代价；新理解带来新的选择，不只是更强技能；最终解法回收既有规则，代价与人物弧相连。

主编要求：强制绑定的爱情线必须记录选择权如何变化；解咒/变形是否兑现主情绪；特殊身份要改变行动方法。奇观既服务识别，也要服务因果。

常见失效：随时新增法术；变形只解决外观却抹去价值问题；契约在需要时有效、不需要时消失。先返修规则，再排特效与台词。

本地化与制作：奇幻不等于无规则；神话名词与原创制度标清。AIGC可扩大视觉规模，人物、道具、空间和伤情仍需连续性控制；不能用“AI可做”代替可交付的镜头测试。

## E 真相追索与封闭危机

核心问题：在信息或行动受限时，谁如何发现真相、辨别威胁并付代价脱困。

立项必须设置：关键真相、对手行动路径、可见线索和误导的真实依据；空间/时间限制；失败代价；观众比主角多知道、少知道还是同步知道。

段落推进：第一假设带来行动和代价；新线索推翻部分解释；主角改变查证方法；高潮通过选择回收关键线索并产生后果。线索揭示应改变行动，而不只是增加神秘名词。

主编要求：公平线索与主观隐瞒分开；认知反转有回溯依据；脱困依靠已建立资源或付出新代价；真凶动机和行动可解释已发生事件。

常见失效：不给必要信息而在最后凭空揭晓；人物因为不检查一眼就能查清的事实而维持危机；反转多但没有稳定规则。返修真相时间线与线索表。

本地化与制作：选择团队可控的封闭空间与危险机制；警方、医疗、司法等现实程序须核查。若没有能力设计完整解答，先缩小谜题，不用开放式结尾掩盖没有答案。

## F 竞技、行动与职业任务

核心问题：人物怎样在明确规则、对手策略和能力限制下完成任务，同时承担关系与价值选择。

立项必须设置：任务胜负标准、规则、关键技术难题、对手策略、团队角色与失败成本。赛事、战斗、法庭或救援应当真的影响剧情。

段落推进：初次任务暴露方法局限；对手改变策略迫使调整；团队或价值冲突抬高成本；最终任务用已建立的能力与新选择取得结果。

主编要求：观众看懂关键胜负；必要专业过程清楚而不堆术语；伤势、技能和装备连续；结果改变资格、资源或人物关系。浪漫可以叠加，但不让职业场面沦为随意宣布输赢的背景。

常见失效：裁判/制度随作者站队；对手永远不会应对；重伤在下一场消失；一句地位声明取代职业任务。返修规则、策略和后果。

本地化与制作：需要专业读者、动作/赛事呈现和成本控制。若核心看点做不到可信可见，暂缓或改题，不以概念热度代替执行能力。

## 混合题材的约束

一部剧可以是“狼人旧爱重逢”“海妖敌对合作冒险”“职业逆袭叠加契约婚姻”，但必须指定主发动机和主回报。辅助线应给主线制造选择或补充回报，而不是每当主线卡住就另开一部剧。

混合开发先做删除检验：去掉辅助元素，核心冲突是否仍完整；加入它以后，人物方法、代价和结局选择是否真正改变。若没有，只是包装；包装可以保留，但不能按新增发动机计算故事容量。
